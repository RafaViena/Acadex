# 🏋️ Acadex

Acadex é um aplicativo simples para gerenciamento de treinos de academia, acompanhamento de evolução física e registro de desempenho esportivo.

Desenvolvido para um projeto pessoal, com foco em simplicidade, praticidade e facilidade de uso.

## 🚀 Funcionalidades

* Cadastro de treinos
* Registro de exercícios
* Controle de séries, repetições e cargas
* Cronômetro de treino
* Timer de descanso
* Histórico de treinos
* Controle de peso corporal
* Registro de impulsão para vôlei
* Estatísticas e gráficos
* Salvamento automático com LocalStorage

## 🛠 Tecnologias

* HTML
* CSS
* JavaScript
* LocalStorage
* Chart.js

## ▶️ Como usar

1. Baixe ou clone o projeto.
2. Abra o arquivo `index.html` no navegador.
3. Comece a registrar seus treinos.

## 📄 Sobre o Projeto

O Acadex foi criado para um projeto e uso pessoal, com o objetivo de centralizar informações de treino, evolução física e desempenho esportivo em uma aplicação leve e fácil de manter.
